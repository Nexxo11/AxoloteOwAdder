# AxoloteOwAdder

![image](https://github.com/user-attachments/assets/afd40f40-25c9-4284-a16e-bf0d9cea5224)

Is a tool for adding and configuring overworld events in the Pokeemerald

## About The Project

AxoloteOwAdder is a tool designed to simplify the process of adding and configuring overworld events in Pokeemerald and its expansions. With this tool, you can insert new overworlds in a matter of seconds, without having to manually edit the game's source code.

### Features

*   Insert and configure overworld events in one click
*   Easy to use graphical user interface
*   Supports both Pokeemerald and Poke-expansion
*   Multi-language support (English and Spanish)

## Getting Started

To get a local copy up and running follow these simple steps.

### Prerequisites

This tool is designed to work on Windows.

### Installation

1.  Download the Latest Release from the [GitHub Releases](https://github.com/Nexxo11/AxoloteOwAdder/releases) page.
2.  Unzip the downloaded file.
3.  Run the `AxoloteOwAdder.exe` file.

## Usage

1.  Run the tool.
2.  Select your project folder.
3.  Configure the project settings (Pokeemerald or Poke-expansion, and Dynamic Pal System).
4.  Select the new overworld to add.
5.  Configure the overworld settings (name, width, height, etc.).
6.  Click on the "Insert Overworld" button.

## Building

To build the tool from source, you will need to have Python and cx_Freeze installed.

1.  Clone the repo
    ```sh
    git clone https://github.com/Nexxo11/AxoloteOwAdder.git
    ```
2.  Install the dependencies
    ```sh
    pip install -r requirements.txt
    ```
3.  Build the executable
    ```sh
    python setup.py build
    ```
